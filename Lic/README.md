# Aspose.Zip license

Place one Aspose.Zip `*.lic` file in this directory to run `python run_examples.py` in licensed mode. The file is not tracked by Git.

If multiple license files are present, the runner selects the first in sorted order, prints its name and ignores the others. Keep exactly one `*.lic` file here for an unambiguous automatic choice.

Alternatively, set the `ASPOSE_ZIP_LICENSE` environment variable to the desired license file path. It takes precedence over automatic discovery. Without a license, the runner warns and uses evaluation mode.
